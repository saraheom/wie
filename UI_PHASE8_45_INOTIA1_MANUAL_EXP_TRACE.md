# Phase 8.45 UI / TestFlight diagnostic notes

Adds one temporary testing control under the existing in-game Diagnostics section: **Arm/Reset EXP Trace**. It is supported only by the exact Inotia1 KTF title. Pressing it resets and starts the native 16/32-bit candidate watcher; it does not modify gameplay or EXP. English and Korean button labels are included.
