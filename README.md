# WIPI Player

The current TestFlight workflow targets **WIPI Player 0.1.52 (Phase 8.52)**. This stabilization build is based directly on Phase 8.50 and preserves the verified Inotia1 global monster-reward overflow repair, save/revival compatibility, the established offline cash-shop protocol, and the existing Inotia2 compatibility/performance work.

Phase 8.52 keeps the Phase 8.50 cleanup and bulk material purchases, and expands the normal Inotia1 cash catalog to 11 records by adding the title-native `무기강화 주문서` and `방어구강화 주문서`. Both revival scrolls remain because the native catalog capacity is 12. `무기강화 주문서`, `방어구강화 주문서`, `힘의 조각`, and `마법의 가지` now all grant quantity **10** per purchase; all other shop entries remain quantity 1.

See the phase-specific notes for compatibility history and TestFlight setup.
